This loop runs 254 times per epoch (8144 images ÷ 32 batch size). Over 20 epochs that's 5,080 weight updates. Each update nudges every weight slightly toward lower loss. VGG19, EfficientNet, MobileNet, ResNet — they all run this exact same loop. Only the architecture of Step 1 changes.
